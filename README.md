# 🌐 Personal Portfolio Website

## 📌 Project Overview

The **Personal Portfolio Website** is a responsive web application developed using HTML, CSS, Bootstrap, and JavaScript. It is designed to showcase my professional profile, technical skills, educational qualifications, internship experience, and academic projects.

The portfolio provides an online platform to highlight my software development knowledge, demonstrate my technical abilities, and share my career achievements with recruiters and potential employers.

## 🎯 Project Objectives

* Create a professional online presence.
* Showcase technical skills and project experience.
* Highlight educational qualifications and internships.
* Provide easy access to contact information.
* Develop a responsive and user-friendly website.

## 🛠️ Technologies Used

* **HTML5** – Structure of the website.
* **CSS3** – Styling and page layouts.
* **Bootstrap 5** – Responsive design and UI components.
* **JavaScript** – Interactive functionality.

## ✨ Key Features

* Home – Professional introduction.
* About Me – Personal and professional profile.
* Skills – Technical skills and programming knowledge.
* Education – Academic qualifications.
* Experience – Internship and work experience.
* Projects – Academic and technical projects.
* Contact – Contact information and social media links.
* Responsive Design – Compatible with desktop, tablet, and mobile devices.

## ⚙️ Installation and Setup

Follow these steps to run the project:

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Explore the portfolio website.

**Alternative:** Open the project in Visual Studio Code and use the Live Server extension.
